# Исправление ориентации надписей

Заменены оба GLB и build_final.py. Исправлены UV (верх картинки соответствует верху фасада), вертикальная раскладка пяти колонн и боковые плоскости Employer, Planning, Floor1Title–Floor4Title. Панели вынесены перед выступами перекрытий. Исправлены нормали и оси: GLB теперь стандартный Y-up, фасад смотрит в +Z.

## Подключение
Замените public/geropharm-house.glb и генератор. Если на сайте был добавлен поворот -90° вокруг X для прежнего нестандартного GLB, удалите его. Не применяйте отрицательный scale и flipY к текстурам GLTFLoader. Очистите кэш модели или измените URL на /geropharm-house.glb?v=uv-fixed.

Рекомендуемая камера Three.js: position (17,17,29), target (0,4.7,0), ортографическая. Проверка проводилась в приложенном демо, не в вашем внешнем сайте.

## Проверка
Chromium: загрузка модели, отсутствие ошибок JavaScript, состояния 0/6 и 6/6, мобильный viewport 390×844. Скриншоты browser-fixed.png, browser-completed.png, browser-mobile.png. Khronos glTF Validator: 0 errors, 0 warnings; информационные сообщения о неиспользуемых атрибутах допустимы. Миссия и слово ГЕРОФАРМ дополнительно проверены распознаванием текста из браузерных снимков. Основной текст мелкий и при общем виде требует приближения.

Это исправление надписей и расположения панелей существующей модели, не новая точная реконструкция референса. Шрифт сборки — DejaVu Sans, как fallback: Verdana.ttf в архиве не предоставлен. Поддержка VERDANA_FONT сохранена. Содержимое формулировок не исправлялось.

Пересборка: python -m pip install -q pillow; python build_final.py. Демо: npm install; npm run dev.
