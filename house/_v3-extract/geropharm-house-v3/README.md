Готовая реконструкция по образцу (фото 5) с Verdana font. В ассеты добавлен Verdana.ttf (placeholder). Текст на фасаде полностью совпадает с образцом. Карточки и логика Cursor остаются без изменений. 

Как пользоваться:
- GLB: geropharm-house-v3/public/geropharm-house.glb
- Тексты на фасаде: секции в geropharm-house-v3/public/sections.json
- Шрифт: Verdana.ttf (помните заменить на лицензионный Verdana.ttf внутри ассетов)
- В ассетах также найденны изображения ценностей и логотипов под образец. 

Инструкция по встраиванию в Cursor и тестированию будет добавлена после окончательной сборки.
