# Обновление модели в существующем сайте / задание для Cursor

## Что внутри

- `public/geropharm-house.glb`: новая модель (~6.3 MB), текстуры встроены, шесть разделов + environment.
- `house-v2.blend`: редактируемая сцена Blender 5.2, с упакованными текстурами и студийными светом/камерой.
- `reconstruct_v2.py`: генератор новой версии (Python + bpy + Pillow).
- `textures/`: все изображения надписей, уже отрисованные Verdana.
- `typography-audit.json`: размер и содержание каждой таблички.
- `public/sections.json`: побайтово сохранён из присланного архива. Это текст карточек, не фасада.
- `src/main.js`: настроенный браузерный пример.
- `browser-idle.png`, `browser-complete.png`: состояние 0/6 и 6/6.
- `browser-mobile.png`, `browser-mobile-card.png`: мобильные примеры.
- `gltf-validation.json`, `browser-test.json`: результаты проверок.

Старый build_model.py удалён: его запуск восстановил бы старую упрощённую модель.

## Запуск демо

Нужен Node.js 20+.

```
npm install
npm run dev
```

Для сборки: `npm run build`. Открытие index.html двойным кликом не поддерживается.

## ВАЖНО: не заменяйте весь существующий сайт этим демо

Попросите Cursor перенести модель и параметры визуализации в ваш текущий компонент.
Существующие карточки, стили сайта, аккаунты и прогресс не нужно перезаписывать.
Архив пользователя содержал исходное standalone-демо, а не весь изменённый сайт со скриншотов.

Готовое задание:

> Подключи новый public/geropharm-house.glb вместо старого. Сохрани существующие тексты
> карточек и систему прогресса. Перенеси настройки камеры и света из src/main.js новой
> версии. Удали старое общее затемнение/перекрашивание материалов в цикле анимации.
> Сохрани базовые цвета GLB. Подсветку меняй по роли материала (glass, light),
> текстовые материалы не перекрашивай и не заставляй светиться.
> Используй userData.sectionId, а не номера мешей или старые имена деталей.
> При необходимости сбрось кэш модели через version query или новое имя файла.
> Сравни с приложенными браузерными скриншотами при 0/6 и 6/6.

## Идентификаторы / API

`foundation`, `floor1`, `floor2`, `floor3`, `floor4`, `mission`.
Окружение — `environment`, оно не является учебным разделом.

GLTFLoader переносит glTF extras в userData. Роль есть в material.userData.role
и в mesh.userData.role. Объекты объединены по разделам и материалам ради снижения
числа draw calls; поэтому не привязывайте логику к порядку мешей.

```
window.houseApp.selectSection('floor2');
window.houseApp.setCompleted(['foundation','floor1']); // заменяет весь список
window.houseApp.getCompleted();
```

Пример хранит прогресс в localStorage под прежним ключом geropharm-progress-v1.
Для пользовательских аккаунтов нужна связь с вашим сервером.

## Шрифт

Использована настоящая Verdana. Основной текст всех инициатив, колонн, ценностей,
миссии и финансовых показателей имеет единый кегль 0.115 единицы модели.
Подписи площадок — 0.13, заголовки — 0.145. Объёмная вывеска — отдельный масштаб.
Перспектива и расстояние до камеры всё равно влияют на видимый размер букв.
Автоматического увеличения коротких надписей больше нет. При переполнении генератор
останавливается с ошибкой: нужно увеличить площадь таблички, а не уменьшить шрифт.

Файлы TTF не включены в архив. Для просмотра они не нужны: текст уже в текстурах,
буквы вывески — в геометрии. Для пересборки укажите свой лицензированный Verdana.ttf:

```
pip install -q bpy pillow
# Linux/macOS, пример:
VERDANA_FONT=/path/to/Verdana.ttf SKIP_RENDER=1 python reconstruct_v2.py
# Windows PowerShell, пример:
$env:VERDANA_FONT='C:\Windows\Fonts\verdana.ttf'
$env:SKIP_RENDER='1'
python reconstruct_v2.py
```

bpy должен быть совместим с версией Python. Для этой сборки использованы Python 3.13
и bpy 5.2.2. Если хочется отредактировать только форму, проще открыть house-v2.blend.
При ручном экспорте из Blender исключите Studio ground, камеру и студийные источники
света, включите экспорт Custom Properties, сохраните шесть родительских групп.
Генератор экспортирует GLB до создания студийного окружения.

## Свет, камера и мобильные устройства

В браузере используется ортографическая камера для ракурса, похожего на референс.
Материалы имеют корректные линейные glTF baseColorFactor, текстуры — sRGB.
Настройки света и свечения находятся в VISUAL в src/main.js.
Стены остаются светлыми и при 0/6; прогресс усиливает окна и тёплые световые полосы.
Не накладывайте прежнее затемнение .69 и усиленное свечение стен поверх новой схемы.

На узком экране отключено вращение, есть кнопки разделов и нижняя карточка.
Камера вписывает дом в доступную область, pixel ratio ограничен.
Статические тени рассчитываются один раз; кадры не перерисовываются после
стабилизации сцены. Для особенно слабых устройств можно отключить shadowMap.
Это не заменяет проверки на реальных iOS/Android устройствах.

## Ограничения точности

Это реконструкция, а не точная исходная 3D-сцена. Изображение не задаёт размеры
скрытых сторон. Логотип и эмблемы ценностей приближённые; фирменные SVG/PNG помогут
сделать их точными. Отдельная висящая плашка «Стратегия 2030» не входит в GLB здания.
Длинный согласованный текст местами отличается от изображения, поэтому его
компоновка тоже отличается. Цвет зависит от света и tone mapping принимающего сайта.
