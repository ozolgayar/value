# Финальная версия реконструкции дома ГЕРОФАРМ

## Важно

В этом пакете **действительно заменён GLB**: `public/geropharm-house-final.glb` и копия `public/geropharm-house.glb` — это пересобранная модель с отдельными группами `foundation`, `floor1`, `floor2`, `floor3`, `floor4`, `mission`.

Добавлены и/или переработаны:
- ступенчатая архитектура и террасы;
- крыльцо, дверь и ступени;
- пять колонн первого этажа;
- производственный конвейер, коробки и биореакторы;
- портфельные карточки, финансовый блок и полоса миссии;
- раздельные зелёный и золотой круги логотипа;
- три иконки ценностей: страсть, амбициозность, ответственность;
- скамейки, растения и фонари;
- весь указанный фасадный текст;
- `sectionId` в extras GLB для интерактивной подсветки сайта.

## Шрифт

В загруженном архиве лицензионного файла Verdana не было, поэтому текущая пересборка использует системный кириллический fallback DejaVu Sans и честно указывает это в `FONT-NOTE.txt`. Я не добавлял фиктивный или переименованный TTF.

Чтобы получить точную Verdana:

```bash
mkdir -p /home/user/verdana
# положите лицензионный Verdana.ttf в /home/user/verdana/Verdana.ttf
python build_final.py
```

## Сайт / Cursor

Для интеграции достаточно заменить `public/geropharm-house.glb`. Текущие карточки можно оставить в Cursor. `public/sections.json` содержит согласованный текст для карточек и интеграции.

Если используется Three.js:

```js
const gltf = await new GLTFLoader().loadAsync('/geropharm-house.glb');
scene.add(gltf.scene);
```

Интерактивные группы доступны по `userData.sectionId` / GLB extras: `foundation`, `floor1`, `floor2`, `floor3`, `floor4`, `mission`.

## Запуск демо

```bash
npm install
npm run dev
```

`build_final.py` — исходник пересборки GLB. Карточки и сайт не являются частью самой модели; они подключаются отдельно в Cursor.
